# Sticker Kit Assets（微信表情包配套素材助手）

本项目提供用于生成微信表情包开放平台所需的**配套素材**及**合辑文案**的工具，严格遵循官方规范。**不包含表情图本身的生成**。

## 核心功能

1. **文案生成**：根据表情形象特点，生成合辑名称、合辑介绍、赞赏引导语，并为每张表情图生成含义词。
2. **素材处理**：内置 Python 脚本 `process_sticker.py` 自动化处理各类图片素材的尺寸、格式、透明度和体积限制。
3. **规范自检**：提供详细的设计自检清单，确保素材符合平台审核标准。

## 素材规范概览

| 素材类型 | 格式 | 尺寸 (px) | 核心设计要求 |
| :--- | :--- | :--- | :--- |
| **横幅图** | PNG | 750 × 400 | **无文字**；**须使用彩色不透明背景**；**主体或背景元素须横向铺满画布，两侧不得留白边、预留空边或任何形式的纯色边** |
| **封面图** | PNG | 240 × 240 | **透明背景**；正面半身/全身像；无白色描边/锯齿 |
| **图标** | PNG | 50 × 50 | **透明背景**；头部正面；无白色描边/锯齿；无方框 |
| **赞赏引导** | GIF/PNG | 750 × 560 | 风格一致；引导用户赞赏；**须使用彩色不透明背景**；文字清晰可见 |
| **赞赏致谢** | GIF/PNG | 750 × 750 | 风格一致；激发分享意愿；**须使用彩色不透明背景**；文字清晰可见 |

## 脚本使用方法

使用内置脚本 `scripts/process_sticker.py` 进行自动化处理：

```bash
# 生成封面图 (240×240, PNG, 透明背景 — 默认)
python3 scripts/process_sticker.py input.png cover.png 240 240 PNG 500

# 生成横幅图 (750×400, PNG, 彩色不透明背景 — 必须关闭透明)
python3 scripts/process_sticker.py banner_input.png banner.png 750 400 PNG 500 False
```

**参数说明：**
`python3 process_sticker.py <input> <output> <width> <height> <format> <max_kb> [transparent=True] [is_animated=False] [loop_gif=False]`
